How it works

Three steps, same as the Python pipeline in this repo.

1

Build a vocabulary

Read the corpus, count every word, and give each one a number. The most frequent word gets the smallest id.

2

Tokenize

Replace every word in your sentence with its id. Words never seen before become <UNK> instead of crashing.

3

See it in 3D

Plot each token in 3D space — position, token id, and how often the word appears — so the vocabulary is visible, not just trusted.

TokenIdMeaning
